# Paper-writing sketches

> Extreme-draft, untested guidance for manuscript prose and attraction
> features after a paper case is selected.

Topic: `paper-writing`

Status: **EXTREME DRAFT / UNTESTED** — none of this companion is binding
manuscript procedure.

## Candidate manuscript pass

One possible check is to draft two short versions of each load-bearing result
paragraph: the neutral evidentiary statement and the form-shaped reader-facing
version. If the second cannot be traced back to the first, the prose has outrun
the result.

## Attraction features used to communicate

Consult [`paper-attractiveness`](paper-attractiveness.md) after the evidence
spine exists. Select an attraction feature because it communicates something
the program intends to convey and has actually found:

- scarce compute or commissioned labels communicate coverage or a reusable
  community asset;
- privileged access communicates otherwise unavailable observational reach
  only when the draft separates the inaccessible advantage from the finding
  or community asset it transfers;
- evocative examples communicate a representative failure mode;
- stakes framing communicates a supported consequence or deployment need;
- normative language communicates an explicit target choice and tradeoff; and
- repeated visual grammar communicates how successive interventions differ.

Do not add a charged example or moral label merely because it makes the paper
feel important. When a useful attraction signal could still leave a misleading
implication, apply the brief honest-footnote rule in
[`paper-attractiveness.sketches.md`](paper-attractiveness.sketches.md): name the
specific mismatch without burying the paper's actual point.
