# Glossary

Project-specific terminology — terms whose meaning here is distinct
from default agent usage. Every named row is topic-like; `topic / refs`
may point to any canonical doc, while each glossary owns a formal
`topics/` collection for dedicated cross-cutting docs.

See [`topics/glossary.md`](topics/glossary.md) for contribution and
regeneration rules.
