##  [ 

![Figure](figures/ba980fc624d853fc90c0b1f8dbc4815a144c0750f9d72a12561d37a6f29340a0.svg)

  ](https://huggingface.co/datasets/hudsongouge/anti-ccp-decensor#schema) Schema 



Column | Description  
---|---  
`id` | sha256 prefix of `user + assistant`  
`source_file` | primary source filename kept  
`source_index` | index within that source file  
`source_family` | `china_refusals` or `deccp`  
`source_variant` | `v1` or `v2`  
`source_files` | all source files that contributed this response (incl. dups)  
`user` | user turn  
`assistant` | assistant turn (dedupe key)  
`chatml` | original ChatML string  
`messages_json` | parsed messages as JSON  
`n_messages` | message count  
`duplicate_count` | 1 + number of dropped response-duplicates  
`duplicate_sources_json` | metadata for dropped duplicates

Exact string match on the assistant response. First occurrence kept; later identical responses are recorded in `duplicate_sources_json` / `source_files` and not emitted as separate rows.
