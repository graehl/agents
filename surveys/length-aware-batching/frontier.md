The relevant open engineering comparison is whether bounded random-band
packing with cross-epoch carry improves the padding/repeat-gap/co-residency
frontier against sorted windows and direct mass-weighted buckets on the
actual weighted corpus. No result is claimed. The simplest falsifier is a
same-draw multiseed sampler comparison including sparse extreme lengths,
highly concentrated row weights, and finite startup/shutdown boundaries.

The literature does not settle which standalone randomness measures predict
endpoint model quality. Revisit only when a candidate sampler is selected
for implementation; this is an unscheduled research question, not a run queue.
