# Illustration style

Prefilled storybook default. Change any line; the agent follows this file.
Read before making, requesting, or placing any image. Pictures are made only
after the author agrees the story is done and confirms this file.

**Illustrations wanted:** a cover plus one per chapter, once the story is
done.
**Medium:** flat vector shapes with a few bold outlines, like a picture
book.
**Palette:** five bright colors plus a dark outline color, chosen once for
the whole book and reused.
**Line and shape:** rounded shapes, thick even outlines, no gradients.
**Mood in three words:** bright, friendly, a little silly.
**Reference points the author named:** none yet; ask when the story is done.
**Format:** SVG, square for the cover, 3:2 landscape for chapter pictures;
no text inside images.
**How images are made:** in this order, whichever is actually available in
the session: a purpose-built illustration model that accepts the story's text
context, then the harness's native image generation, then SVG drawn by the
agent (the default for this flat style). Record the tool and prompt template
here once chosen.
**Where images go:** `story/images/`, named `cover.svg` and
`<chapter-number>-<slug>.svg`.
**Alt text:** every image gets a one-sentence description for readers who
cannot see it.

## Not wanted

close-up.
