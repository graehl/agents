| base | A reusable capability or technique that contributes files and root instruction fragments, may extend multiple bases, and is not independently offered in New Project. The reserved `base` is intended to contain only universal items. | [Format](FORMAT.md#multiple-bases) |

| preparation turn | The automatically submitted first agent turn that incorporates the entered intent into project instructions and documentation and verifies the scripted starter before app implementation. | [Creation](README.md#approved-delivery-sequence) |
| project template | A named selection of multiple capability bases plus project-specific files and explicit overrides, later completed by scripted stand-up and a preparation turn. | [Format](FORMAT.md) |
| template library | A finite inventory under a configured repository-relative content root, containing templates and the bases they reference. | [Source boundary](FORMAT.md#library-and-source-boundary) |
| template override | An explicit replace, prepend, append, or omit operation applied by the selected template after its inherited file union is resolved. | [Overrides](FORMAT.md#explicit-template-overrides) |
