# Continuity ledger

Facts the draft asserts. Add a row when a scene states something checkable;
walk the table during the continuity pass. The owning sheet is authority.

| fact | where stated | owning sheet | status |
|---|---|---|---|
| <e.g. the bridge is two days' walk from town> | ch. 3 ¶4 | `setting/river-road.md` | consistent |
| | | | |

Status values: `consistent`, `conflict` (say with what), `unresolved` (the
sheet has no entry yet).
