# Program

Develop a compact, empirical operating layer that helps capable
filesystem-first agents pursue user goals reliably across projects, harnesses,
and interrupted sessions.

The program combines durable instruction policy, recoverable repository state,
lightweight coordination and safety mechanisms, and reusable agent-facing
tools. It favors evidence-backed, trigger-scoped guidance and reversible
workflows: preserve user and peer work, make important intent and provenance
recoverable, verify consequential claims and actions, and continuously remove
prompt or process cost that does not improve outcomes. It is not a
provider-specific agent framework or a substitute for each project's own
technical judgment and local rules.
